## 二、H5 版验收步骤

1. 双击打开 `h5/dist/布仕曼洗护-H5版.html`（或浏览器打开后 F12 切换手机视口 390×844）
2. 首页：点「全部服务」→ 进入服务项目列表
3. 点任一服务卡 → 服务详情（价格 / 工期 / 流程 / 保障）→ 点「在线预约」
4. 预约页选日期时段、调整数量 → 提交 → 生成订单并跳转订单详情
5. 底部 tab「订单」→ 列表筛选（全部/进行中/已完成）→ 点订单卡进详情
6. tab「装备档案」→ 新增/编辑装备；tab「我的」→ 会员次卡、客服电话
7. 预期：全程无白屏、无控制台报错（生产构建已验证零告警）

## 三、微信小程序版验收步骤

1. 微信开发者工具 → 导入项目 → 选择 `miniprogram/` 目录 → AppID 选「测试号」
2. 编译后检查：首页宫格入口、tabBar 四图标、服务列表/详情
3. 预约提交 → 订单列表 → 订单详情（六态时间线）→ 模拟支付
4. 装备档案增改、会员次卡购买、养护知识文章阅读
5. 预期：全部页面正常渲染，无缺文件报错（源码 85 文件已校验）
