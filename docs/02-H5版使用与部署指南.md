# H5 版使用与部署指南

## 一、直接使用（零依赖）

`h5/dist/布仕曼洗护-H5版.html` 是**单文件成品**：CSS、JS（React 生产构建）、全部图标（内联 SVG）均已内嵌，无任何外部请求。

- 双击即可在浏览器打开使用（手机效果最佳，建议 390×844 视口或真机）
- 也可发给任何人、放进任何静态目录，永不出现 404

## 二、部署方式（任选其一）

| 方式 | 步骤 |
| --- | --- |
| 任意静态托管 | 把该 HTML 上传即可（Nginx/OSS/EdgeOne Pages/Vercel 均可），建议文件名改为 `index.html` |
| Nginx | `root /var/www/bushiman;` 后 `cp 布仕曼洗护-H5版.html /var/www/bushiman/index.html` |
| 服务器直出 | `python3 -m http.server 8080` 临时验证 |

路由为 hash 路由（`#/services`、`#/orders` …），无需服务端 rewrite 规则。

## 三、从源码构建

依赖：[Bun](https://bun.sh) ≥ 1.1。

```bash
cd h5
# 1) 生产构建（--production 会正确切换 React 生产运行时并压缩）
bun build src/offline-h5-entry.tsx --target=browser --production --outdir /tmp/offline-h5
# 2) 组装单文件 HTML 到 dist/
python3 scripts/build_offline_h5.py
```

> 注意：不要用 `--define process.env.NODE_ENV='production'` 代替 `--production`——后者才会把 JSX 运行时一并切换为生产版；前者会保留 dev 运行时并打坏其内部逻辑（`jsxDEV is not a function`）。

## 四、源码说明

```
h5/src/
├── offline-h5-entry.tsx   打包入口（挂载 #root）
├── App.tsx                全部页面视图 + 哈希路由 + Toast/确认弹层
├── store.ts               状态与 Mock 数据层（服务/订单/装备/次卡，含 api 抽象）
├── icons.ts               全量内联 SVG 图标
└── h5.css                 品牌样式（深绿 #1F4A3C + 金棕 #B08850）
```

## 五、接入真实后端

`h5/src/store.ts` 中的 `api` 对象是唯一数据出入口（列表/详情/下单/支付回调等）。将各方法的 Mock 实现替换为 `fetch(BASE_URL + ...)` 即可，页面层无需改动。数据保存在内存，刷新即重置——接入后端后自然持久化。
