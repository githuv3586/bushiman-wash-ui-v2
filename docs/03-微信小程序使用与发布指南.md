# 微信小程序使用与发布指南

## 一、导入运行

1. 下载并安装「微信开发者工具」（稳定版）
2. 导入项目 → 目录选择本仓库 `miniprogram/` → AppID 选「测试号」（正式发布时替换）
3. 编译运行。首页 / 服务 / 预约 / 订单 / 装备档案 / 会员次卡 / 我的 全部可用（演示模式）

## 二、页面清单（12 页）

| 页面 | 路径 | 说明 |
| --- | --- | --- |
| 首页 | `pages/index` | 品牌头 + 服务宫格 + 次卡促销 + 养护知识 |
| 服务项目 | `pages/services` | 分类筛选 + 价目与工期 |
| 服务详情 | `pages/service-detail` | 价格/流程/保障 + 在线预约 |
| 确认预约 | `pages/booking` | 日期时段/数量联动价格/提交 |
| 我的订单 | `pages/order-list` | 三态筛选 + 订单卡 |
| 订单详情 | `pages/order-detail` | 六态时间线 + 模拟支付 |
| 装备档案 | `pages/gear` | 档案列表 |
| 编辑装备 | `pages/gear-edit` | 新增/编辑装备 |
| 养护知识 | `pages/articles` | 文章列表 |
| 文章详情 | `pages/article-detail` | 正文 + 关联服务 |
| 会员次卡 | `pages/membership` | 次卡购买 |
| 我的 | `pages/profile` | 门店信息/客服/次卡入口 |

## 三、代码结构

```
miniprogram/
├── app.js / app.json / app.wxss     全局（tabBar：首页/订单/装备档案/我的）
├── config/index.js                  USE_MOCK、BASE_URL、门店信息【占位】
├── utils/
│   ├── mock.js                      演示数据与状态机
│   ├── request.js                   请求封装（对接后端时使用）
│   ├── pay.js                       支付封装（wx.requestPayment）
│   ├── icons.js                     页内 SVG 图标
│   └── util.js                      订单号/日期等工具
├── images/                          tabBar PNG 图标（微信 tabBar 仅支持 PNG/JPG）
└── pages/                           12 个页面（js/json/wxml/wxss 四件套）
```

## 四、对接后端与发布

1. `config/index.js`：`USE_MOCK: false`，`BASE_URL` 填已备案的 HTTPS 接口域名
2. 替换 `【门店地址】` `【门店电话】`
3. `project.config.json` 填正式 AppID
4. 微信公众平台：开发管理 → 服务器域名 → 配置 request 合法域名
5. 开发者工具「上传」→ 公众平台提交审核（类目建议「生活服务-洗护」）→ 发布

## 五、注意事项

- tabBar 图标必须为 PNG（已提供 8 张：4 组选中/未选中），页内图标为内联 SVG
- 订单号规则：`BSM + yyyyMMddHHmmss + 4位随机`
- 演示模式下订单状态按时间自动推进，便于验收六态 UI；接后端后由接口驱动
